双时相变化检查工具 Electron 版 3.3.4

一、安装
1. 双击“release\3.3.4\双时相变化检查工具-安装程序-3.3.4.exe”。
2. 安装向导可以自行选择安装路径。
3. “附加任务”页面可以勾选或取消“创建桌面快捷方式”。
4. 安装完成后可从桌面快捷方式或开始菜单启动。

二、窗口和系统托盘
1. 程序启动后自动最大化。
2. 点击右上角 X 不会退出，而是隐藏到 Windows 右下角系统托盘。
3. 单击托盘图标会重新显示并最大化程序。
4. 需要彻底退出时，右键托盘图标并选择“彻底退出”。

三、目录与文件
A：第一时相图片目录。
B：第二时相图片目录。
Mask：黑底 RGB Mask 目录。
A 和 B 使用文件名完全相同的图片进行配对。
支持 png、jpg、jpeg、tif、tiff、bmp 和 webp。
旧版 Mask 和 mask_labels.json 可直接继续使用，无需转换。
新建 Mask 与 A、B 同名，例如 A/B 为 tile.jpg 时，Mask 保存为 tile.jpg。

四、快捷键
A / ←：上一张
D / →：下一张
快速连续上一张/下一张时只渲染最终停留图片，避免为略过的 4K 图片重复解码
空格 / Tab：切换前后时相；Q/E 操作过程中也可使用，不会清空已画点
B：闪烁
闪烁速度：可选极快 150ms、快 250ms、标准 350ms、慢 600ms、极慢 1000ms；选择后自动保存
V：左右对比
X：互换当前同名 A、B 原始文件在两个目录中的内容；再次按 X 可换回
S：显示/隐藏 Mask；Q/E 操作过程中也可使用
C：打开/关闭标签管理器
Q：彩色多边形标注；Enter 或右键保存，保存后保持标注状态，可直接继续标下一块；Backspace 撤回点，Esc 取消
E：删除标注；点击删除同色连通区域，Shift+点击可绘制删除多边形
F：AI 圈选；左键目标点，Shift+左键或右键排除点，Enter 写入当前标签
Delete：把当前图片组移动到 deleted_pairs
Shift+Delete：彻底删除当前图片组（会再次确认）
U / Ctrl+Z：撤销普通删除
R / 0：重置视图
+ / - / 鼠标滚轮：缩放
按住鼠标中键拖动：平移图片；左键拖动不再平移
双击图片不再重置缩放或位移

五、标签快捷键
1. 按 C 或点击底部标签按钮打开标签管理器。
2. 选择 0～255 中的标签，在“切换快捷键”处点击“录入快捷键”。
3. 按下希望使用的按键或组合键，例如 F1、F2、Ctrl+Alt+1。
4. 点击“保存标签”或“保存并设为当前”后生效。
5. 每个快捷键只能分配给一个标签；软件已有功能快捷键不能重复占用。
6. 在 Q 标注过程中也能按标签快捷键切换颜色，不会丢失已画的多边形点。

六、Mask 规则
1. 标签颜色就是写入 Mask 标注区域的实际 RGB 类别值。
2. 未标注背景始终保持纯黑色 (0,0,0)。
3. 主界面红色轮廓仅用于查看，不会写入 Mask 文件。
4. 纯白色等非黑色标签均可正常标注。
5. 标签名称、颜色、快捷键和置顶状态保存在程序旁的 mask_labels.json；
   如果安装目录无写入权限，程序会安全回退到当前用户配置目录。

七、多点标注辅助线
彩色标注或区域删除时，选中第一个点后会显示一条从最后一个点跟随鼠标移动的虚线，帮助确认下一条边的位置。
在当前 A/B 图像视口的黑色留白中点击或移动时，标注点和辅助虚线会自动吸附到最近的图像边缘或角点；左右对比时不会跨到另一幅图。
鼠标离开当前图像视口时辅助线会自动隐藏，重新移入后继续显示。
单点删除和替换颜色仍需点击图像内部，不会吸附。

八、性能说明
Electron 版只保留最近使用的少量已解码图片，连续翻页不会无限累积内存。
相邻大图会提前准备交互预览；翻页、缩放和平移时使用轻量预览，停止操作后自动恢复原始清晰度以及精确 Mask 颜色、透明度和红色边界。
Mask 保存和大面积连通区域删除在主进程异步完成，处理期间界面保持可查看。

九、AI 圈选（MobileSAM）
1. AI 圈选使用内置 MobileSAM ONNX 模型，本机离线运行，不上传图片，不需要 Python、显卡或自行训练。
2. 先通过闪烁或左右对比确认变化；新增目标切到 B，拆除目标切到 A，再按 F。
3. 左键点击目标内部作为正点；圈多时用 Shift+左键或右键点击多余区域作为排除点。
4. Backspace 撤回最后一个点，Enter 将候选区域写入当前标签颜色，Esc 取消。
5. 第一次点击当前图片需要计算图像特征，后续补点会明显更快。
6. SAM 只负责按点击提示圈轮廓，是否属于真实双时相变化仍由人工判断。
